什么是Coding Agents？

即定位专注于写代码场景的AI Agents， 比如Claude Code， Codex，Grok Build， Pi，以及最新出来的DeepSeek Harness…

1 🦙 小龙虾 与 Coding Agents

小龙虾（OpenClaw）跟 Coding Agents 其实不完全一样。

  • 小龙虾偏服务器端，偏Remote， 用户访问它的时候，是通过其它外围channels，比如telegram，飞书之类IM产品；但Coding Agents更偏Local，通常跑在开发者使用的开发机上，虽然现在很多人喜欢结合UU/Tailscale/Paseo/Herdr等工具远程访问这些Coding Agents，但Coding Agents骨子里还是偏Local开发机上的Agents实现。
  • 小龙虾更偏通用Agents， Coding Agents更偏Coding；
  • 小龙虾的受众更广， Coding Agents的受众通常是研发；

2 🦙 WorkBuddy 与 Coding Agents

WorkBuddy的产品定位更偏办公， Coding Agents的产品定位还是Coding。

3 🦙 CLI，TUI 与 GUI

同为Coding Agents，

但Coding Agent跟Coding Agent其实也不一样

比如Claude Code更偏重CLI产品形式

而Codex更偏GUI产品形式（虽然也有rust版的CLI版）

而像Herdr之类agents管理类的CLI工具，其实有点儿向TUI偏移了。
